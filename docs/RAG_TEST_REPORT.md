## 초기 구현 시점의 자료 검색 확인

사용자가 제공한 ZIP은 별도 로컬 작업환경에서 변환했습니다. 121문서(원문115+정리6), 8164구간, 작은 원본 후보3개를 준비하고 SQLite 무결성과 원본 해시를 확인했습니다. 원문 D105의 소요조회15일 권장 표, 관리전환합의서 관련 D042 등, 조달청 관리전환 서식 D003과 시스템 매뉴얼 인계/인수 항목이 검색되는지 확인했습니다. 예시 질의의 결과 ID·원문 위치는 비공개 패키지 retrieval-check.json에 보관했습니다. 모든 법규의 현행성·모든 질의 정답률을 전수 검증한 것은 아닙니다.

## 초기 구현 시점의 브라우저 범위

Browser 연결 도구는 탭 읽기만 제공하므로 Playwright Chromium으로 검증했습니다. 데스크톱1440×1000, 모바일390×844에서 앱 페이지·업무도우미 렌더, 콘솔 페이지 오류 없음, 검색→근거 카드→프로그램 기능 이동, 미연결 AI 차단, 근거 없음, 대화 비우기·새로고침 시 삭제와 가로 넘침 없음을 확인했습니다. 기존11개 시나리오 합계에는 엑셀·상태·배송·양기관 전체 인계·CSV·사진 검사가 포함됩니다.

스크린샷은 test-results/rag-desktop.png, rag-mobile.png에 생성해 CI 아티팩트로 보존합니다. 이 작업에서는 생성 캡처를 별도 이미지뷰어로 열어 육안 대조하지 못했으며 픽셀 단위 시각 검수 완료를 주장하지 않습니다. Codex 인계에 실제 로컬/NAS 브라우저 검수를 포함했습니다.

## 초기 구현 시점의 미완료 항목 (위 NAS 후속 결과에서 갱신)

실제 DeepSeek4.1 키·계정 모델 목록·생성 정확도 검증, 기존 NAS 재배포·업무망 접속, 기관간 문서 공유/외부반출 승인, 실제 사용자 문의20개 이상의 정답·근거 평가, 공식 최신 법령 전수 대조는 Codex/업무담당 마무리 대상입니다. 테스트 통과가 기관 보안심사 또는 행정적 적법성 승인과 같지 않습니다.
