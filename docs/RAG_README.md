## 구현 범위

`AI 업무도우미`에서 프로그램 사용법, 공유 허용된 제공판 지침·서식, 전체 범위를 검색합니다. 질문과 근거를 DeepSeek Chat Completions에 보내 근거ID가 달린 답변을 받는 어댑터를 구현했습니다. 검색은 외부 모델 없이 동작하고, 생성은 키·승인·사용자 동의가 필요합니다. **NAS 반영과 검색 검수는 완료했으며 실제 API 키를 이용한 생성은 미완료입니다.** 기존 사진 분석 공급자는 바꾸지 않았습니다.

질문 → 한국어 키워드/두 글자 검색 + BM25 순위 → 중복 구간 제한 → 제공판·OCR·설계자료 표시 → 허용된 근거만 모델 입력 → JSON/인용ID 검증 → 답변과 근거 카드. 후속 질문에는 앞선 사용자 질문 최대3개를 문맥으로 사용합니다. 서버가 답변을 검색 결과처럼 위장하지 않으며, 근거가 없거나 공급자 오류면 검색 결과와 오류 상태를 분리합니다.

이 버전은 **SQLite FTS5 BM25 + 한국어 2글자 검색 기반 RAG**입니다. 벡터 임베딩·시맨틱 재정렬은 미구현이며 이를 의미검색 완성이라고 표시하지 않습니다. 코드/지침에 사용되는 업무 용어와 문서명 검색을 먼저 확보한 구성입니다. 실제 문의 평가 후 필요하면 승인된 임베딩 모델을 별도로 추가할 수 있습니다.

## 실제 준비한 자료와 공개 코드의 분리

별도 비공개 배포 ZIP은 기존 MD 자료집을 실제로 변환해 생성했습니다.

- 원본 문서별 항목126개에서 중복9개와 지침 본문이 아닌2개를 구분: 고유 원문 변환 자료115개.
- AI가 정리한 개발 참고자료6개를 **DESIGN(법적 근거 아님)**으로 별도 분류.
- 합계 **121문서 / 8,164검색 구간**, 별도 프로그램 안내8개는 공개 코드에 포함.
- 모든 지침은 `UNVERIFIED_PROVIDED_EDITION`: 현행 법규 대조를 완료한 것으로 표시하지 않음.
- PDF 페이지가 명시된 경우 해당 페이지, HWP는 내부 구역·표, 그리고 실제 MD 줄 위치를 보존. HWP 구역을 실제 페이지라고 만들지 않음.
- 작은 독립 서식 후보3개는 원본 SHA-256을 대조해 함께 제공. 나머지는 변환본문 검색만 가능하며 원본이 없는 다운로드 버튼은 표시하지 않음. 후보가 빈 현행 서식임을 검증한 것은 아님.
- 자료에 포함된 개인·기관 사례의 반입/기관 간 공유/외부전송 적합성을 사람이 검토해야 함. 기관별 거래·첨부·계정 DB는 검색하지 않음.

공개 저장소에는 **자료 본문·검색 DB·원본 파일을 넣지 않습니다.** 원본 ZIP 전체도 Docker 이미지에 넣지 마세요. 별도 자료 ZIP을 비공개 서버 디렉터리에 해제해 읽기 전용으로 연결합니다. `md/`, `originals/`, `index.sqlite`, `manifest.json`은 같은 버전으로 보관합니다.

## 딥시크 모델 설정

2026-11-01 공식 문서를 확인한 기본값은 `RAG_MODEL=deepseek-flash`입니다. DeepSeek-V4.1-Flash 계열의 호출 별칭이며 실제 제공 버전은 공급자가 바꿀 수 있으므로 `npm run rag:check -- --live`로 계정 모델 목록과 반환 model을 확인합니다. 모델명 `deepseek-4.1`을 발명하거나 임의 다른 공급자로 대체하지 않습니다.

공식 참고: https://api-docs.deepseek.com/api/list-models/ , https://api-docs.deepseek.com/api/create-chat-completion/ , https://api-docs.deepseek.com/guides/json_mode/ , https://api-docs.deepseek.com/news/news261017/

고정 주소 `https://api.deepseek.com/chat/completions`, Bearer 인증, JSON mode, 비사고 모드, 최대 출력2600토큰, 타임아웃60초, 응답256KB 제한입니다. 실제 문서 외부전송은 기관 정책에 따라 별도 검토해야 합니다. 코드에서 보관 여부를 제어하지 못하는 공급자 데이터 정책까지 '무보관'으로 보장하지 않습니다.

```dotenv
# 서버에만 저장. 예시는 키가 아니라 변수명입니다.
RAG_MODEL=deepseek-flash
DEEPSEEK_API_KEY=
RAG_AI_ENABLED=false
RAG_EXTERNAL_APPROVED=false
RAG_DAILY_LIMIT=50
RAG_LIBRARY_ENABLED=false
RAG_CORPUS_DIR=
RAG_LIBRARY_EXTERNAL_APPROVED=false
```

`RAG_EXTERNAL_APPROVED`는 질문/프로그램 근거 전송 승인입니다. `RAG_LIBRARY_ENABLED`는 모든 인증 업무기관에 공유해도 되는 참고 지침을 검색에 열기 위한 설정입니다. `RAG_LIBRARY_EXTERNAL_APPROVED`는 해당 지침의 외부 모델 전송 승인으로 별도입니다. 값을 true로 설정하는 것 자체가 법적/기관 승인을 취득하는 절차는 아닙니다.

사용자 화면의 '설정됨'은 접속 성공을 뜻하지 않습니다. 없는 키, 401/403/429, 지연, 빈 JSON, 잘린 응답, 없는 인용ID는 정상 답변으로 처리하지 않습니다. API 키를 UI·로그·프롬프트·Git에 넣지 않습니다.

## 설치·변경·재현

미리 생성한 비공개 자료 ZIP은 **새 버전 디렉터리**에 압축 해제합니다. 기존 DATA_DIR·DB·uploads를 변경하지 않습니다. 키 없이 `npm run rag:check`로 프로그램 근거를 확인하고, `RAG_CORPUS_DIR`와 지침 허용을 설정한 뒤 다시 검사합니다. 이 검사는 manifest의 인덱스 해시·문서/구간 수를 대조합니다.

제공 MD ZIP에서 새 인덱스를 재현하는 명령(Python3.10+, FTS5 지원 sqlite3):

```sh
python3 scripts/prepare-rag.py --md-zip /private/서울교육청_물품전환_MD자료집.zip --original-zip /private/전체문서.zip --out /private/rag-v05-new
```

Windows는 설치된 Python의 `py -3` 또는 `python`을 사용합니다. 스크립트는 오프라인이고 기존 출력폴더가 있으면 중단합니다. 파일명이 같아도 내용을 무조건 최신판으로 인정하지 않습니다. 모든 현행성은 미검증으로 시작합니다. 입력자료가 새로 바뀌면 실제 질의의 근거/표/시행일을 검수하고 버전을 교체해야 합니다.

프로그램 사용법은 `server/rag/app-guide.mjs`의 버전별 안내8개입니다. 전체 저장소/환경파일 자동수집이 아닙니다. 화면과 기능이 바뀌면 이 파일과 테스트를 함께 갱신하세요. 법령 현행성 자동 웹크롤링은 하지 않습니다.

NAS에서는 `deploy/nas.rag.compose.yml`을 기존 앱/네트워크 Compose에 추가해 `/app/rag-private`를 읽기 전용으로 마운트합니다. 사전 생성한 인덱스로 운영하면 런타임 Python/벡터DB가 필요 없습니다. 자세한 보존 업데이트는 `docs/CODEX_RAG_HANDOFF.md`를 따르세요.

## 보안·한계

로그인·기관 업무역할·CSRF를 기존 서버에서 확인합니다. ADMIN의 운영권한만으로 지침 업무자료를 조회하게 하지 않았습니다. AI에 도구나 승인/수정 권한을 주지 않았습니다. 질문·답변은 화면 메모리에만 남으며 서버에는 대화본문을 저장하지 않습니다. 외부 호출 한도는 별도 `DATA_DIR/rag-usage.sqlite`의 기관/일자/횟수로 보존합니다. 실패도 한도에 포함하며 같은 사용자의 동시 생성은 한 개로 제한합니다.

원문 다운로드는 문서ID, 안전한 내부 경로와 SHA-256을 확인합니다. 모델이 만든 URL을 실행하거나 표시하지 않습니다. 프롬프트 내 원문은 신뢰하지 않는 데이터로 취급합니다. 인용ID 검증은 **존재하지 않는 출처를 막는 기술적 검사이지, 모든 문장과 근거의 의미 일치를 증명하지 않습니다.** 실제 딥시크 평가 및 담당자 확인이 필요합니다. 금액·기간·예외·법적 의무는 생성 답변만으로 자동 결정하지 마세요.

원본이 없는 서식을 다운로드했다고 표시하지 않습니다. 제공한 HWP·XLSX 후보는 최신 빈 양식 여부 확인 대상입니다. 완전한 기관별 문서 ACL, 대화 장기보관/감사·삭제정책, 벡터 검색, 전문 법률 검토는 별도 범위입니다.
