## 사용자가 준비할 최소 자료

비식별 실제 엑셀 한 개, 키가 필요한 공급자의 이용승인/서버 자격, 승인된 AI 모델과 자료전송 범위, 운송업체의 적용 단가(있을 때)다. 없는 것은 미설정으로 남기고 수동 기능을 먼저 시연한다. 현재 앱은 물품번호를 사진으로 검증해 법적 식별번호를 자동 확정하거나 에듀파인 공식 승인을 대행하지 않는다.
