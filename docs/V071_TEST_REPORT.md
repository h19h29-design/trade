## 수정 및 회귀 근거

추가 테스트4개를 먼저 실행해 모두 실패하는 것을 확인한 후 수정했다.

1. **대기 OZD의 24시간 만료:** 기존 loadImport가 모든 업로드에 같은 기한을 적용해 며칠 뒤 변환기를 연결해도 재개가 막혔다. WAITING OZD는 원본 보존 상태로 재개하고, 변환 완료 시 readyAt부터24시간을 계산한다. 업로드일은 바꾸지 않는다. 업로드 이력과 실제 재개 권한도 동일 기준으로 계산한다.
2. **변환 원본 무결성:** 내려받기만 검사하던 SHA-256을 자동변환과 수동 변환표 연결 전에도 검사한다. 손상된 원본은 외부로 보내거나 변환완료로 처리하지 않는다.
3. **본문 인용 링크 잔여문구:** `[S1](#source-S1)`의 ID만 지워 주소가 남던 현상을 수정한다. 출처 전용 링크 전체를 제거한다. 일반 Markdown, 연도 표기, 서버 인용ID 검증은 그대로다.
4. **읽기 지원:** 대화내역을 접근 가능한 log/live 영역으로 표시한다. 출처목록은 기존처럼 참고자료 버튼을 누르기 전에는 표시하지 않는다.

새로운 DB 마이그레이션은 추가하지 않았다. v0.7의 schema4를 사용한다. 기존24시간 엑셀 미리보기 제한/등록 멱등성/기관격리는 유지한다.

## 환경과 한계

Browser 연결은 탭 읽기만 제공하여 실행환경 Playwright를 사용했다. 데스크톱1440×1000/모바일390×844 캡처를 생성했고 DOM·상호작용·가로폭을 검사했다. 로컬 이미지 도구와 웹 이미지 열기가 실패해 이 후속 작업에서 캡처 육안 검수는 완료하지 못했다. 실제 NAS의 화면 최종 확인을 Codex 인계에 남겼다.

서브에이전트 실행 도구는 제공되지 않았다. 단위검사/빌드와 브라우저 설치를 독립적으로 병렬 실행했으며, 에이전트가 코드 검토를 수행했다고 주장하지 않는다. Codex 인계에는 입력/OZD, UI, 통합·보안 세 역할과 파일 소유범위를 명시했다.

실제 OZ 해석 엔진, 사용자 OZD/XLSX 전수 대조, 기존 키로 조달청·DeepSeek 실응답, 기관 지침 외부전송 승인, NAS백업복원·배포는 아직 이 작업에서 실행하지 않았다. OZD 자동변환은 허가된 실제 엔진 연결 후만 사용한다. 프로그램 검색/파일 등록의 테스트 통과를 외부 연결 완료로 표시하지 않는다.
