## 1. 실제 제공된 Excel 파일의 형식 확인
요청 파일: `(전체기관대상) 관리전환 소요조회 목록 (2194개).xlsx`

- Sheet1 `A1:P2197`, 제목 1행, 머리글 2행, 데이터 **2,194행**(3~2,196행), 마지막 합계 1행
- 합계 수량 **2,194개** (데이터행 수와 수량 총합은 별도 검사)
- 16개 열 중: 물품고유번호(물품대장) / 고유번호(스티커) / 물품조직명 / G2B목록번호 / G2B물품분류명 / G2B목록명 / 취득일자 / 최초취득금액 / 수량 / 취득금액 등
- 원본 자산번호는 1,902개 고유값. **249개 번호그룹이 중복**, 중복 행은 합계 **541행**. 원본에서는 같은 번호가 다른 부서에서 쓰이는 경우가 확인됨.
- 중복된 번호를 임의의 새로운 공식번호로 바꾸지 않는다. 해당 행은 물품 초안으로 만들되 **자산대장 자동 연결을 보류**하고 원래 번호·소관 부서·취득정보·스티커 번호를 원본 스냅샷에 보존한다.
- 날짜 텍스트 `20200320` 등은 `YYYY-MM-DD`로 정규화하되 원본 파일·열의 원값도 그대로 보관한다.
- `최초취득금액`과 `취득금액`은 다른 열. 임의로 `취득단가`로 단정하지 않는다. `내용연수 만료일`은 일반 자산번호에 합치지 않는다.
- 실제 원본 파일은 공개 Git 저장소·자동 CI·제3자 AI로 업로드하지 않는다. 이 PR의 대량 테스트는 **같은 16열·행수·머리글과 중복 특성을 모사한 합성 엑셀**만 사용한다.

## 2. 3,000행 등록
- `shared/import-limits.mjs`로 `MAX_IMPORT_ROWS=3000` 통합. 엑셀 파서·최종 검증·미리보기 커서 및 진행범위를 함께 변경.
- 합계·소계 행은 제외하되 **본문 행을 몰래 자르지 않는다**. 3,001 데이터 행은 모두 실패하고 0건 등록된다.
- 3,000행 외에도 파일 크기, ZIP 확장 크기, 20개 시트, 64열, 총 30만 셀, Worker 메모리·시간 제한은 계속 적용.
- 대량 문서는 원본 분석·미리보기(40건 페이지) 후 담당자가 수정·확인하고 나서 비공개 초안을 생성한다.
- 외부 공급자 질의는 자동 무제한 호출하지 않는다. 50묶음 이하만 기본 자동 보완, 대량 자료의 추가 보완은 **50건씩** 사용자가 선택하며 남은 건수/진행률을 표시.

## 3. 단일 테스트 계정
새로운 별도 테스트용 `DATA_DIR`를 만든 뒤:
```bash
npm ci
npm run build
npm run demo:single
```
접속 `http://localhost:4310` → **ID admin / 첫 비밀번호 1234**.
- 한 개 **활성 로그인 계정만** 발급. 이름은 admin이지만 업무 역할은 `EDITOR`(시스템 관리자나 법적 승인권한 아님).
- 설정 → `테스트 아이디·비밀번호 변경`. 현재 비밀번호 입력, 새 ID, **12자 이상 새 비밀번호**. 변경 후 세션 전체 만료, 옛 ID/비밀번호 사용 불가.
- 최초 `1234` 사용 상태에는 **localhost/127.0.0.1에서만 실행 가능**, 외부 HTTPS 공개 불가. 인증정보 변경 전 원격 서비스에 공개하지 않는다.
- 이 계정 모드는 `DEMO_MODE=true && SINGLE_DEMO_MODE=true`인 별도 비운영 DB 전용이며 운영에서 기능을 켜거나 기존 기관 DB에 초기 계정을 삽입하지 않는다.

## 4. 물품 삭제 / 보관 / 초기화
`내 물품 삭제·복원` 메뉴.
- 개별/선택 삭제, 내 기관 전체 보관, 업로드파일 단위 보관, **샘플 300건만 초기화**.
- 삭제는 검색·AI 추천·물품 상세·현물사진 접근에서 제외하되, DB·감사·원본·인계이력을 지우지 않는 **복구 가능 보관**.
- 삭제 대상 건수/제외 건수/대상 스냅샷을 먼저 확인; 실제 실행은 재인증용 **현재 비밀번호와 정확한 확인 문구** 요구.
- 신청·인계 이력이 있거나 심사 중인 묶음은 자동 삭제하지 않음. 샘플만 초기화는 명시적으로 표식된 합성자료만 대상.
- 삭제 보관함에서 선택 복원. 게시된 실제 기관 물품은 복원 후 비공개 상태에서 재검토; 합성 샘플은 테스트용 이전 상태로 복원.
- 동일 원본 업로드는 기존 등록영수증·중복검사 정책을 유지하므로 삭제 이후 새 원본 등록보다는 보관함 복원부터 확인.

## 5. 샘플 300건과 검색
- 단일 테스트 모드 시작 시 합성 가상 기관에 **공개표시된 예시 물품 300묶음 자동 생성**. 실제 기관을 사칭하지 않으며 모든 생성 사용자 계정은 비활성화돼 로그인할 수 없음.
- `npm run demo:seed`로 샘플 멱등 재검사/누락분 생성. 재실행해도 총건수가 300을 초과하지 않음.
- 목록/AI 공통 검색 정규화: 물품번호 하이픈/공백, 모델명·띄어쓰기, 캐비넷/캐비닛, 책장/책꽂이 등 동의어, `~말고` 제외표현.
- 정확번호/모델 일치에 더 높은 관련도 점수 부여하고 일반 검색에는 최신순·관련도 정렬.
- 비공개·보관 삭제·예약 소진·비활성 기관은 다른 기관의 AI 추천에서 제외하며, 내 관리 화면은 내 기관만 조회.
