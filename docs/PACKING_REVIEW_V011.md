## 파일 등록 흐름
`파일 업로드 → 원본/분석 결과 저장 → 담당자 부분 수정 → 확인하고 등록 → 실제 비공개 초안 생성`

이전처럼 파일을 올리자마자 실제 물품을 만드는 경로를 새 AI 화면에서 호출하지 않는다.
`registration_previews`에만 분석 결과를 보관하며 이 단계의 `lots`/`assets`/`imported_rows`는 0건 증가다.
담당자 확인 API가 현재 버전·원본 SHA256·해석한 원본행 해시·기관 권한을 검사하고 기존 원자적 가져오기를 실행한다.
같은 파일의 동시 등록·중복 확인·새로고침도 원본 행 중복 방지와 완료 영수증을 사용한다.

수정 가능한 표시 항목은 품명·제조사·모델·규격·설명·부서다. 대장 원본의 품명·수량·번호·폐품·취득정보는 보존한다.
수량 오류는 임의 숫자 변경이 아니라 원본·직접 등록 경로에서 대조해야 한다. 확인 후에도 상태는 DRAFT이고 게시 승인은 따로 받는다.
기존 수동 엑셀 등록/기존 API 호환 경로는 유지하지만 새 AI 등록 UI는 prepare→enrich→confirm 경로만 사용한다.

### 참고사진
기존 조달청 API에서 정확한 식별번호로 받은 이미지와 `PROCUREMENT_IMAGE_RIGHTS_CONFIRMED=true` 설정이 모두 있는 경우에만
기존 서버 이미지 안전검사(고정 공식 도메인, DNS 고정, 크기·형식 제한)를 사용한다. 최대 10개 분석항목에 임시 보관한다.
담당자가 선택을 취소할 수 있고 최종 확인 시에만 `catalog_images`로 연결한다. PHOTO 증빙으로는 사용하지 않는다.
제품 사진 찾아보기는 검색 링크다. 일반 웹사진을 수집하거나 이용권을 자동 승인하지 않는다.

## 트럭 계산
- `/packing`: 예시 물품부터 입력. `/packing/:lotId`: 접근 가능한 기존 물품의 확인된 입력값을 가져온다. 누락 치수는 0으로 표시해 입력을 요구한다.
- 12종/합계2,000개. 0.1cm 단위로 포장 외곽 치수는 올림, 차량 내부는 내림.
- 바닥 평면의 직사각형 빈공간을 분할하면서 비중첩 배치를 만든다. 품목을 footprint/긴변/중량 순으로 각각 배치하고 적은 회차를 선택한다.
- 90도 수평 회전만 허용. 기울여 싣기, 포개지는 실제 형상, 이종물품 위로 쌓기 등은 계산하지 않는다.
- 쌓기: 동일 품목만, 확인된 최대개수와 추가높이로 기둥을 구성한다. 높이/중량 한도로 감소시킨다.
- 매 회차 총중량, 개체수, 물품경계와 비중첩 조건을 지킨다. 2백만 후보 검사 한도를 넘으면 해당 차량을 실패로 표시한다.
- 계산 결과는 **가능한 배치의 구성 예시**, 전역 최적해/안전검사/기사 배차 판단이 아니다. 물품 고정·문폭·축하중·무게중심은 현장 확인이 필요하다.
- 브라우저에서 첫8회차/회차별200칸을 그린다. 미리보기 제한과 달리 비용·수량은 전체 배치 기준이다.

### 기본 예시값 (실제 차량/요금 보장 아님)
| 분류 | 내부 크기 cm | 허용 중량 kg | 기본료 | 10km 초과 km당 |
|---|---|---:|---:|---:|
| 소형 예시 | 280×160×160 | 1,000 | 60,000원 | 1,000원 |
| 중형 예시 | 460×200×200 | 2,500 | 110,000원 | 1,500원 |
| 대형 예시 | 620×230×230 | 5,000 | 170,000원 | 2,000원 |

운임 = 회차 × (기본료 + 초과거리료) + 선택 상하차/인력/계단 + 부가세.
표시 범위는 계산값의 80~130%로 설계한 예시일 뿐 신뢰구간·실제 견적이 아니다.
서버에 기존 `SHIPPING_RATE_CARD_JSON` 설정이 있다면 이를 보존한다. 기본값만 예시다.
자동 AI 추천도 규격과 경로 정보가 있는 경우 새 적재 계산을 사용한다. 키가 없으면 입력거리로 독립 계산 화면을 사용할 수 있다.

## API / 데이터
- POST `/api/shipping/packing`
- POST `/api/registration-preview/:id/prepare`
- GET `/api/registration-preview/:id?offset=0`
- PATCH `/api/registration-preview/:id/items/:key`
- POST `/api/registration-preview/:id/enrich`
- POST `/api/registration-preview/:id/confirm`
- GET `/api/registration-preview/:id/items/:key/reference`

인증·기관 분리·CSRF·업무역할·시간당 제한을 기존 정책과 함께 검사한다.
새 schema7은 분석/분석사진 테이블만 추가한다. 원본 DB/업로드는 보존한다.
이전 앱은 schema7 DB를 열 수 없으므로 롤백은 현재 DB를 삭제하지 않고 이전 백업을 **별도 경로**에 복원한다.
