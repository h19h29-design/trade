## 실제 조달청 확인

공식 공공데이터포털 15129417의 HTTPS Swagger에서 고정 경로와 소문자 serviceKey를 다시 대조했다. 사용자가 제공한 RTF는 키 데이터로만 읽었으며 보호된 서버 경로에 저장한다. 원문 키·키 포함 요청 URL은 Git/브라우저/로그/보고서에 쓰지 않는다. 응답이 키를 반사해도 저장·전달 전에 차단한다.

공식 명세의 예시 식별번호23062106으로 실제 조회가 성공했다. 품목은 태양광발전장치/이투지/DE-BIPV-5 표기이며 실제 회사명 제안은 주식회사 이투지다. 제조업체명 응답은 품명·회사·모델이 합쳐진 원문이므로, 검증 가능한 형식에서만 회사명을 분리하고 원문과 분리 제안 표시를 함께 제공한다. 별도 모델 필드가 없으므로 모델명을 자동 생성하지 않는다. 사용자가 선택한 필드만 초안에 입력하며 원본 번호는 바꾸지 않는다.

실제0건 응답과 잘못된 키의403도 확인했다. 응답 지연/통신 실패, 제공기관429·JSON/XML 사용량 오류, 앱의 기관별/전체 한도는 독립된 코드·문구로 처리하고 주입 테스트로 검증했다. 사용량 제한을 실제로 유발하기 위한 대량 요청은 하지 않았다.

공식 포털의 이 데이터셋 이용허락범위는 ‘제한 없음’이다. 실제 응답의 `img.g2b.go.kr:7073` HTTPS 사진을200/image/jpeg로 받아 서버 DNS/IP 고정·리디렉션 차단·MIME/크기 검사·WebP 재인코딩을 확인했다. 비표준 포트 허용은 이 정확한 공식 호스트의7073에만 한정한다. 참고사진은 catalog_images BLOB에 출처·식별번호·확인자와 저장하며 PHOTO 게시증빙으로 계산하지 않는다. 참고사진만으로 게시 관문을 통과하지 못하는 회귀검사를 유지한다.

## 실제 엑셀과 합성 자료 구분

사용자가 추가 제공한 실제 XLSX는 별도 로컬 검수 DB에서만 검사했다.20행·총134개를20초안으로 등록했고 원본 파일 SHA-256, 모든 행의 원본 품명·목록번호·수량과 원본 셀의 날짜·단가를 대조했다. 실제 양식의 G2B목록번호/등록수량 머리글 자동 연결을 보완하고, 순번을 기관 자산번호로 오인하지 않도록 했다. 전체 품명은 snapshot에 보존하고 표시 품명/규격만 분리한다.

이 실제 파일에는 부서·기관 자산번호 열과 삽입사진이 없다. 없는 값을 추정하지 않으며 모든 초안은 상태 미확인·불용결정 미검증이다. 실제 번호13종을 캐시해20초안의 조달정보 조회·빈칸 반영과 업로드 이력을 확인했다. 실제 XLSX/원본 행/검수DB/화면 원문은 공개 Git·Docker 이미지·현재 NAS 시연 DB로 옮기지 않는다.

사진 행 선택·현물/개인정보 확인·연결, 부서별 분리·앞자리0 자산번호는 별도 합성 XLSX로 검수했다. 조달 일괄 보완은 실제 API 응답의 브라우저 전달만 잠시 보류해 중단 버튼을 조작했으며1/2에서 멈춘 후 재개해2/2 빈칸 반영을 확인했다. 모의 응답을 실제 성공으로 표시하지 않았다. 같은 번호의 반복 조회에서 서버의 실제 외부 호출은1회만 발생했다.
