# 쓸모잇다 v0.13 — 가져올 물품·주소·운송비

기준 main: `c1a23b251ddc918638474faf9daea86f5796da24` (v0.12 배포 검수 문서 병합)
이번 변경은 source/PR이며 운영 NAS, DB, RAG corpus, 모델·키, Cloudflare를 변경하지 않았다.

## 사용 흐름
1. 타 기관의 승인된 물품을 전체 물품 찾기 또는 AI 물품검색에서 **가져올 물품 담기**로 선택한다.
2. 물품 상세에서 필요 수량을 정한 경우 **선택 수량 운송비 보기**로 그대로 전달한다.
3. 상단 **가져올 물품** → 수량 → **받을 주소**를 정한다. 같은 탭의 담기 목록만 계정별 sessionStorage에 보관한다. 주소·키는 이 저장소에 넣지 않는다.
4. **예상 운송비 계산**을 누르면 기존 AI로 부족한 크기·무게를 보완하고, 서버가 거리와 트럭 배치에 따라 계산한다. 유료 AI/API가 입력할 때마다 반복 호출되지 않도록 명시적으로 실행한다.
5. 출발지별 차량·회차·예상액, 전체 합계, 가정값 출처를 확인한다. 다른 차량을 선택해 비교하면 합계도 다시 표시된다. 크기·출발지 수정은 이번 계산용이며 원본 물품에는 반영하지 않는다.
6. 담기·견적은 신청, 재고 예약, 실제 운송계약·배차·결제가 아니다. 받기 신청과 인계 승인 절차는 기존 그대로다.

## 주소와 기존 API
- 카카오 우편번호 공식 SDK의 `kakao.Postcode.embed()`를 사용한다. 주소선택 자체는 별도 키 없이 가능하며 인터넷이 필요하다. 제공기관 로고를 가리거나 SDK를 재배포하지 않는다.
- 정확한 주소→좌표: 기존 `LOCATION_ENABLED` + `KAKAO_REST_API_KEY`. 주소별 전송동의 후 기존 `geocodeAddress`를 재사용한다.
- 도로거리: `ROUTE_ENABLED`와 기존 `KAKAO_MOBILITY_REST_API_KEY`를 먼저 사용한다. 비어 있으면 `KAKAO_REST_API_KEY`를 사용하지만 해당 앱의 Mobility 사용권한은 별도로 확인해야 한다. 키가 있음을 호출 성공으로 표시하지 않는다.
- 도로 API가 없거나 실패하면 좌표 직선거리 ×1.3, 또는 지원 지역 대표점 ×1.3(최소8km)을 **가정거리**로 표시한다. 실제 도로거리와 구분한다.
- 키 없이 지원하는 대표점은 서울 25구와 코드에 명시한 일부 도시다. 미지원 지역은 임의 좌표를 생성하지 않고 정확한 좌표 연결을 요구한다. `부산 강서구`를 `서울 강서구`로 오인하지 않는다.
- 출발지: 게시기관의 확인된 상차주소가 우선. 없으면 기관 소재구 대표점을 사용하거나 담당자가 이번 계산용 주소를 지정한다.
- 주소 좌표는 서버가 발급한 30분짜리 사용자·기관 결합 토큰으로만 전달한다. 타인 토큰, 만료 토큰, 임의 클라이언트 좌표 주입은 거부한다. 서버 재시작 후에는 주소를 다시 확인한다.

## 크기 판단과 비용 산정
치수/무게의 각 항목은 다음 순서로 보완한다.
1. 담당자가 이번 계산에 직접 입력한 포장 치수
2. 현물 확인된 등록값 / 미확인 등록값 (서로 구분)
3. `1600×600×720mm` 같이 단위가 명시된 규격의 직접 추출
4. 기존 Hive/DeepSeek 모델을 이용한 추정 (자료전송 승인 + 사용자의 동의가 있을 때만)
5. 알려진 물품 유형의 기본 가정값 (의자·책상·모니터 등)

기존 숫자·실측값을 AI가 덮어쓰지 않는다. 일반 제품사진이나 현물사진의 3D 실측을 수행했다고 주장하지 않는다.
AI에는 공개 품명·모델·규격과 이미 알려진 치수만 보내며 별도로 입력한 주소·기관명 필드는 제외한다. 입력 문구 자체에 개인정보가 들어가지 않도록 공개물품 검수 정책을 유지해야 한다.
알 수 없는 품목의 미지 치수는 `추가 정보 필요`로 남기고 전체 합계를 0원이나 확정값으로 표시하지 않는다.

운임은 기존 `SHIPPING_RATE_CARD_JSON`이 있으면 보존해 사용하고, 없으면 기존 **예시 단가**를 사용한다. 모델은 금액을 생성하지 않는다.
- 기존 v0.11 2D 직교 배치 엔진 + 높이/허용중량 검증
- 기본 2cm 여유, 90도 수평회전, 임의 쌓기 없음
- 12종/총2,000개, 출발기관·출발주소별 별도 차량 계산
- 서로 다른 출발지 사이의 다중경유/합배송 최적화는 하지 않음
- 차량별 회차×기본/거리료 + 선택한 상하차·인력·계단 + VAT. 부가작업 입력은 출발지마다 적용한다.
- 범위는 기존 예시 계산의 80~130% 범위이지 신뢰구간이 아니다. 추정 규격·대표점일 때 실제 견적 차이가 클 수 있다.
- 카카오 도로는 승용차 경로이며 화물차 통행·높이·중량·축하중·무게중심·물품 고정·문폭은 운송업체 확인 대상이다.

## 보호한 경계
- 타 기관의 PUBLISHED + VERIFIED + 활성기관 + 신청가능 수량만 견적 대상
- 내 기관/비공개/삭제보관/중단/부족수량 제외
- 외부 호출 전과 응답 직전 재확인: 계산 중 수량·공개상태·버전 변경 시 오류로 재선택 요구
- 실제 예약, 수량 차감, 자산대장 수정, 승인 생성, 기존 데이터 초기화 없음
- 비용 외부 API·LLM 호출은 사용자별/전역 동시성 제한과 호출한도 적용
- 외부 원문 오류·키를 응답에 반사하지 않고 가정 모드·실패 상태를 구분

## 브랜드
공식 표기는 **쓸모잇다**. 주요 로고에서 `잇`과 `다`를 작은 연결선·양끝 점으로 이어 **잇—다**의 뜻을 표현한다.
로그인, PC/모바일 헤더·사이드바, 푸터, 브라우저 제목, favicon, 현재 제품 안내/RAG 문구를 변경했다.
접근성 이름은 `쓸모잇다`로 읽으며 연결선은 장식이다. 기존 사용자 계정, trade 도메인, 저장소 이름, `mulppum-ieum` 이미지 식별자, NAS 경로, DB, 환경변수, 과거 배포기록은 호환성 때문에 변경하지 않는다.
DB schema는 **8 유지**, 신규 마이그레이션 없음.
