# 개선사항 접수 · v0.5.1

## 데이터 변경·복구 계획

SQLite user_version 2→3의 추가 마이그레이션으로 `feedback`과 `feedback_attachments`만 추가한다. 기존 물품·계정·대장·첨부 행은 변경하지 않는다. 개선사항 첨부는 기존 `files`/`uploads`에 저장하고 연결 테이블로 구별하므로 기존 백업의 DB·첨부 해시 검사에 포함된다. 기존 업무 파일의 접근권한은 그대로 유지하고 개선사항 첨부에만 별도 권한을 적용한다.

NAS 교체 전 앱을 중지하고 v2 DB·uploads를 일관되게 백업한다. 별도 경로 복원→v3 마이그레이션에서 기존 테이블 전체 행 보존→로그인·파일 접근 검증 후 교체한다. 실패 시 v3 원본과 신규 의견을 보존하고 검증한 v2 백업을 **새 DATA_DIR**에 복원해 이전 릴리스를 실행한다. v3 DB 위에 구버전을 직접 실행하거나 기존 DB를 덮어쓰지 않는다. RAG 자료팩·별도 사용량 DB와 기존 Cloudflare·포트·네트워크 설정도 보존한다.

## 기능과 권한

- 모든 로그인 사용자가 기능 제안·오류·사용성·기타 의견을 접수한다. 일반 사용자는 본인 접수만, 운영관리자는 전체 접수와 첨부를 확인한다. 다른 기관 또는 같은 기관의 다른 일반 사용자에게 공개하지 않는다.
- 제목·내용과 최대5개 첨부를 하나의 요청으로 저장한다. 하나라도 실패하면 전체 등록을 되돌리고 새 파일만 정리한다. 브라우저 입력·선택 파일은 실패 시 유지한다.
- 운영관리자는 접수/검토 중/반영 완료/보류와 답변을 기록한다. 처리 상태는 개선사항 관리용이며 물품 게시·기관의 공식 승인 권한과 별개다.
- 사진은 JPEG/PNG/WebP를 WebP로 재인코딩하고 EXIF를 제거한다. PDF·HWP/HWPX·XLS/XLSX·DOCX/PPTX·TXT/CSV·ZIP은 허용 확장자·형식을 검사해 파일당8MB까지 받으며 다운로드로만 제공한다. 실행 파일·HTML/SVG는 받지 않는다.
- 의견과 첨부는 RAG 검색·외부 AI 전송에 사용하지 않는다. 비밀키·개인정보·실제 업무 증빙 대신 필요한 설명이나 비식별 화면을 첨부한다.

## 검사

서버 검사는 기존73개에 개선사항7개를 더한80개다. 작성자/동일기관 타사용자/타기관/관리자 파일 ACL, CSRF, 이미지 재인코딩·EXIF 제거, 동일 요청 재시도, 상태·답변 버전 충돌, 허용하지 않는 파일/8MB/5개 제한, DB 저장 중 오류의 전체 롤백과 기존 파일 보존, 첨부 백업복원, v2→v3 보존·멱등을 검사한다. 실패 주입은 합성 테스트 환경에서만 실행한다.

브라우저 검사는 기존11개에 두 시나리오를 추가한다. 사진·PDF 접수의 실패 입력 보존→재시도→다운로드→관리자 답변→작성자 조회, 390px 더보기 접근→HEIC 안내→선택 취소 후 재접수와 가로 넘침을 확인한다. 프로그램 사용 안내는9개로 확장하여 `개선사항 접수` 검색에서 해당 기능으로 이동할 수 있다. 비공개 지침 공유·DeepSeek·기존 사진 AI 설정은 바꾸지 않는다.
