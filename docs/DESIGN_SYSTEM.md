# 물품이음 디자인 기준 (v0.6)

화면을 고치거나 새로 만들 때 이 기준을 따릅니다. 값은 `src/styles.css` 맨 아래 「디자인 정리 v0.6」 층의 `:root` 토큰에 있습니다. 새 색이나 크기를 직접 쓰지 말고 토큰을 쓰세요.

## 1. 원칙

1. **담당자가 한 번에 판단할 수 있게.** 수량·상태·증빙 여부처럼 결정에 필요한 정보는 크게, 설명은 작게 둡니다.
2. **공식 처리와 시연을 섞지 않게.** 시연·미연결·AI 제안은 항상 눈에 띄는 띠나 배지로 구분합니다.
3. **교무실 PC와 휴대폰 둘 다.** 1440px 데스크톱과 390px 휴대폰에서 가로 스크롤 없이 쓸 수 있어야 합니다.

## 2. 색

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--primary` | `#147d64` | 주요 버튼, 선택된 메뉴, 강조 숫자 |
| `--primary-dark` | `#0c604d` | 주요 버튼 눌림·올림 |
| `--primary-soft` | `#e6f3ee` | 선택된 메뉴 배경, 입력칸 초점 테두리 빛 |
| `--primary-line` | `#bfe0d3` | 카드 올림 테두리, 초점 윤곽 |
| `--ink` | `#1f3229` | 제목·본문 |
| `--ink-2` | `#3d5147` | 메뉴·보조 버튼 글자 |
| `--muted` | `#5d6c64` | 설명·작은 글자 (흰 배경 대비 5.5:1, 바탕색 위 5.2:1) |
| `--faint` | `#8a978f` | 메뉴 묶음 제목처럼 읽지 않아도 되는 표시 |
| `--line` / `--line-strong` | `#e1e8e3` / `#cfd9d2` | 구분선 / 입력칸·칩 테두리 |
| `--canvas` / `--surface` | `#f6f8f7` / `#ffffff` | 바탕 / 카드 |
| `--ok` `--warn` `--bad` (+`-soft`) | 초록·주황·빨강 | 상태 알림. 브랜드 초록과 섞어 쓰지 않음 |

- 작은 글자(13px 이하)는 `--muted`보다 연하게 쓰지 않습니다. 이전 회색 `#738078`은 13px에서 대비가 4.5:1에 못 미쳐 바꿨습니다.
- 상태색은 글자만 칠하지 말고 배지·아이콘 모양과 함께 씁니다(색을 못 보는 사람 배려).

## 3. 글자

- 글꼴: **Pretendard** (npm `pretendard@1.3.9`, 필요한 글자만 내려받는 방식으로 앱에 포함). 서버 보안 정책(CSP)이 외부 글꼴을 막기 때문에 CDN을 쓰지 않습니다. 없으면 맑은 고딕으로 대체됩니다.
- 한글 줄바꿈: `word-break: keep-all`. 단어 중간에서 줄이 바뀌지 않습니다. 긴 영문·번호는 `overflow-wrap: anywhere`로 넘침을 막습니다.
- 크기: `--fs-xs 12` · `--fs-sm 13` · `--fs-md 15` · `--fs-lg 17` · 제목은 기존 `h1` clamp(24–32px).
- 굵기: h1·h2 700, h3·카드 제목 650, 본문 400, 메뉴 550(선택 시 750).
- 휴대폰 하단 메뉴 글자는 11px 아래로 내리지 않습니다(이전 9px).

## 4. 모양과 간격

- 모서리: `--radius-sm 8` (칩·작은 버튼) · `--radius 12` (입력칸·버튼) · `--radius-lg 16` (카드·패널).
- 그림자: `--shadow-1`은 카드 기본, `--shadow-2`는 카드에 마우스를 올렸을 때만.
- 버튼은 위로 뜨는 움직임 대신 눌릴 때 1px 내려가는 정도만 움직입니다. 움직임 줄이기 설정이면 전환 효과를 끕니다.

## 5. 구성 요소 규칙

- **사이드바:** 메뉴를 「물품 / 우리 기관 / 업무 도우미 / 설정」으로 묶습니다. 선택된 메뉴는 배경과 왼쪽 막대로 표시하고 `aria-current="page"`를 붙입니다.
- **제목 줄(PageHead):** 상태 배지(`나눔 중` 등)는 제목 바로 옆에 둡니다. 버튼 같은 동작은 오른쪽 끝에 둡니다.
- **물품 카드:** 사진 → 분류(작게) → 물품명 → 상태별 수량 순서. 수량 태그는 사진 위 왼쪽 아래.
- **물품 상세:** 신청 칸이 오른쪽 위 첫 자리. 「배송비 예상」 같은 부가 동작은 신청 칸 아래에 둡니다.
- **분류 칩(휴대폰):** 한 줄로 옆으로 넘기고, 오른쪽 끝을 흐리게 해서 더 있다는 것을 보여 줍니다.
- **필터 줄(휴대폰):** 2열 격자(지역 | 최소 수량 / 관심물품 | 정렬).

## 6. 확인 방법

- `npm run build` 후 `npm run demo`로 열고 1440px·390px 두 크기에서 주요 화면(로그인, 물품 찾기, 물품 상세, 올리기, 신청·인계, 우리 기관 업무)을 확인합니다.
- `document.documentElement.scrollWidth <= innerWidth` (가로 넘침 없음)를 e2e 테스트가 확인합니다.

## 7. 로고 시안 (미적용)

현재 로고는 화살표 두 개입니다. 「물품」과 「이음」이 함께 보이는 시안 두 개를 `docs/design/`에 두었습니다. 팀이 고르면 `public/favicon.svg`와 사이드바 로고에 반영합니다.

- `logo-a-link.svg` — 이어진 두 상자 (기관과 기관을 잇는다)
- `logo-b-loop.svg` — 상자를 감싸는 순환 화살표 (다시 쓴다)
