# Codex 마무리 — v0.10 AI 핵심 기능

이번 코드는 디자인 PR #2의 브랜치에서 이어졌다. 먼저 대상 PR head와 운영 커밋 차이를 확인하고, 별도 기능 브랜치의 변경을 누락시키지 않는다.

```text
https://github.com/h19h29-design/trade
AI 핵심 기능 작업 브랜치 codex/ai-core-20261109에서 검수·보존 배포를 마무리해줘.
AGENTS.md, docs/AI_CORE_V010.md, docs/AI_CORE_TEST_REPORT.md, docs/NAS_DEPLOYMENT.md를 읽어.

1. 현재 작업트리·운영 SHA·DB/uploads/RAG/.env 경로부터 확인해.
   기존 데이터/계정/키/터널/다른 서비스는 삭제·초기화·덮어쓰지 마.
   일관된 백업과 별도경로 복원 확인 후 업데이트해.
   reset --hard, down -v, prune, DB 삭제 금지.

2. 기존 Codex에 넣어둔 DeepSeek·조달청·카카오 키를 그대로 재사용해.
   키값·비밀파일 전체·키가 포함된 URL을 출력하거나 Git에 올리지 마.
   모델은 RAG_MODEL 기존값으로 확인하고 없는 모델명으로 임의 대체하지 마.
   AI_CORE_DATA_APPROVED는 물품/검색 데이터 외부전송이 승인된 경우만 true로 설정해.
   사용자 동의 체크박스와 서버 승인 둘 다 있어야 외부 AI를 호출한다.
   기존 법령 RAG/사진 AI 모델 설정과 지침 코퍼스는 바꾸지 마.

3. 실제 비식별 OZD/엑셀로 드래그 → 자동 원본 검증 → 비공개 초안 →
   조달 번호조회 → AI 원문 추출 → 결과/재시도까지 검수해.
   원본 행별 번호·수량·취득정보·폐품 표기가 그대로인지 대조해.
   잘못된 번호·유사 후보·AI가 만든 모델명은 자동 확정하면 안 돼.
   별도 OZ Viewer를 설치할 필요가 없는 지원형식은 내부 변환기를 그대로 써.
   초안 완료를 게시 완료로 표시하거나 독립 검토를 우회하지 마.

4. 검색은 현재 공개된 타 기관 물품만 사용해야 해.
   ‘회의용 의자 20개’, ‘업무용 모니터 5대’, ‘의자 말고 책상’,
   부족수량 허용/미허용, 없는 물건, 비공개·예약변경을 확인해.
   100점 기준 항목·장단점·근거 버튼이 실제 데이터와 일치하는지 확인해.
   실제 DeepSeek 응답은 별도로 최소20질문을 시험하고 할루시네이션·근거 누락을 보고해.
   네트워크/쿼터 오류면 검색·초안이 남는지도 확인해.

5. 물품의 크기·무게·확인된 상차 위치와 받는 기관 주소를 넣고 배송 비교를 시험해.
   주소/경로 API 동의와 실제 응답을 확인해. 없는 데이터는 ‘확인 필요’여야 해.
   기본 단가는 시연용이므로 실제 업체 견적이라고 표시하지 마.
   실제 배송업체 단가표가 있을 때만 SHIPPING_RATE_CARD_JSON을 설정해.
   예약·배차·결제는 이번 범위가 아니야.

6. npm ci, npm test, npm run build, npm run test:e2e와 데스크톱·모바일 육안검수를 해.
   기존 RAG 대화창·접힌 출처·독립 게시검토·인계·인수·대장흐름을 회귀 검수해.
   실제 환경에서 확인 못한 항목은 완료라고 쓰지 마.

7. 수정분만 커밋·푸시하고 사용자가 승인한 PR 병합/배포 범위에서 진행해.
   최종 보고에는 배포 SHA/주소, 실제 모델 ID, API 실접속,
   원본 대조, 추천 정확도, 배송 가정, 남은 문제를 나누어 보고해.
```
