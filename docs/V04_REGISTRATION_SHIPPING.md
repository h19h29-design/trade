## 1. 등록 흐름

`물품 올리기 → XLSX/XLS 선택 → 시트·머리글·열 연결 확인 → 오류 검증·미리보기 → 비공개 초안 등록 → 사진·상태·불용 증빙 → 독립 검토 → 게시`

일반 XLSX와 구형 OLE XLS를 읽습니다. 8MB, 20개 시트, 시트별 약 2,000개 데이터 행과 64개 열이 상한입니다. 첫 30행에서 머리글을 제안하며 제목·결재란을 가진 표도 머리글 행을 직접 선택할 수 있습니다. 숨김 시트·매크로·암호화 파일·HTML을 XLS로 위장한 파일은 대상으로 삼지 않습니다. 병합된 다단 머리글은 최종 열 이름 행을 선택하여 수동 연결하세요. 수식은 실행하지 않고, 연결한 열에 수식이 있으면 값으로 붙여넣은 파일을 요청합니다.

기관 자산번호, 물품분류번호, 물품식별번호를 구분합니다. '물품번호'라는 모호한 열은 자동 분류하지 않습니다. 텍스트의 앞자리 0, 숫자 표시형식, 날짜, 원본 행·열·파일 해시를 보존합니다. 엑셀을 이미 숫자로 저장해 없어졌던 앞자리 0은 만들어내지 않습니다.

품명·정수 수량이 필수입니다. 같은 품명/규격/분류·식별번호/불용결정번호·일자/회계일 때만 선택적으로 묶습니다. 결정번호가 없으면 합치지 않습니다. 자산번호 없는 행에도 초안은 생성하지만 가짜 자산번호를 발급하지 않습니다. 인계 시 실제 대장행을 연결해야 합니다.

합계행 자동 제외는 **연결한 품명 열**의 `합계/총계/소계/총합계`를 기준으로 합니다. 합계 표기가 다른 열에만 있고 품명이 비어 있으면 오류로 차단됩니다. 이 경우 원본은 보관하고 업로드할 사본에서 합계행을 제거한 뒤 다시 검증하세요. 실제 양식의 합계 위치를 모두 지원한다고 판단하지 않습니다.

확정 등록은 하나의 DB 트랜잭션입니다. 일부 행 충돌 시 전체 신규 등록을 되돌립니다. 같은 원본·매핑을 다시 확정하면 기존 결과를 반환하고, 같은 파일 행을 중복 등록하는 것도 막습니다. **엑셀 수량은 조사 시작값이며 현물실사·불용승인으로 간주하지 않습니다.** 생성 상태는 비공개/미확인/미검수입니다. 현재 학교의 실제 최신 양식 파일을 이 개발 세션에서 받지 못했으므로 합성 표로 검증했으며, 운영 전에 실제 비식별 샘플 열 매핑을 확인하세요.

## 2. 조달청·AI 제품 보조

초안을 저장한 후 별도의 보조 패널을 사용합니다. 입력 중인 변경을 먼저 저장해야 분석할 수 있습니다.

- 조달 조회: 8자리 물품식별번호 우선, 결과가 없으면 입력 품명으로 후보 검색. 기관 자산번호로 조달 번호를 추측하지 않습니다.
- AI: 선택한 현물/명판/결함 사진 최대 3장과 입력 품명을 전송합니다. 기관 자료전송 승인 설정과 사용자 동의를 모두 요구합니다. 증빙문서·대장 원문 전체를 보내지 않습니다.
- 자동 보완: 조달 결과가 없고 AI 설정·사진·동의가 갖춰진 경우에만 AI로 넘어갑니다. 조달 장애와 '검색 결과 없음'은 안내문으로 구분합니다.
- 제안에는 출처, 정확번호 일치/품명 후보/AI 제안을 구별합니다. 제목·제조사·모델·설명·분류·현물 조달번호 중 선택한 것만 초안에 반영합니다. **대장 원본 코드, 실사 수량, 불용결정, 승인 상태는 절대 자동 변경하지 않습니다.**
- 분석 중 초안이나 사진·품명이 바뀌면 제안을 적용하지 않습니다. 제안 ID, 모델, 입력 해시, 적용 필드·주체를 기록합니다.
- 모델이 읽은 치수·중량은 참고 출력만 합니다. 사진 비례로 정밀 실측하거나 내부 고장/작동 정상을 확정하지 않습니다. 수량 추정도 자동 확정하지 않습니다.

사진 첨부에는 '품명'과 '전체/명판/결함/구성품'을 붙입니다. 사진 품명은 물품 검색에 포함되고, 보조 패널에서 그 품명으로 조회할 수 있습니다. 품명 수정은 초안에서만 가능하고 편집자로 기록되어 본인 독립 검토를 방지합니다.

공식 상품 참고사진은 조달 응답에 안전한 HTTPS 주소가 있고 이용조건을 확인한 경우에만 표시합니다. 기관 현물사진과 구분하고 증거사진으로 쓰지 않습니다. 서버는 공식 도메인 허용목록, 공개 IP 검사/DNS 고정, 리디렉션 금지, 크기·시간 제한, 이미지 재인코딩을 적용합니다. 사진이 없거나 차단되면 텍스트 후보만 사용합니다.

## 3. 대량 상태 빠른 입력

전체 양호/사용감/미확인 또는 예외수량 배분을 제공합니다. 예: 총80개에서 사용감20, 수리검토10을 입력하면 양호50으로 계산됩니다. 미확인 수량도 따로 남길 수 있습니다. 합계 초과·음수·소수는 거부하며 담당자가 선택한 검수 범위만 기록합니다. '전체 양호'를 누른 것이 전수검수 완료를 의미하지 않습니다. 상태 변경 후 초안을 저장해야 합니다.

## 4. 배송비 예상 (확정 견적·운송 예약 아님)

물품 상세와 메뉴에 '배송비 예상'을 제공합니다. 저장된 포장 치수를 불러오거나 직접 입력하고 배송 수량, 개당 무게, 안전한 겹침 수량과 추가 높이, 출발/도착 주소, 거리, 상하차/추가 인시/계단/통행료/VAT 가정을 반영합니다. 필수 값이 채워지면 예상액을 자동 갱신합니다. 잘못된 입력에서는 이전 예상액을 표시하지 않습니다.

차량별 적재함 가정 안에서 평면 배치(가로 회전 허용)와 중량을 동시에 확인해 회차를 계산합니다. 물품을 뒤집거나 한 적재묶음 위에 다른 묶음을 쌓는 것을 임의 가정하지 않습니다. 등록 차량에 안 들어가면 전문 업체 별도견적을 안내합니다. 이는 실제 화물 적재·운행 안전성 판단을 대체하지 않습니다.

기본 단가는 **시연용 가정**입니다. 차량·거리단가·작업비·부가세율 및 80~130% 예시 범위를 실제 시장가격/견적 보장으로 표시하지 않습니다. 협약 업체 단가가 확보되면 `SHIPPING_RATE_CARD_JSON`으로 버전·단가표를 교체하세요. `sample:false`여도 '등록 단가 기준 예상액'일 뿐 확정 견적이 아닙니다. 업체명/출처·적용일을 label/version에 명확히 기록하세요.

거리 방식은 세 가지입니다.

| 방식 | 표시/조건 |
|---|---|
| 직접 입력 | 담당자가 확인한 편도 도로거리 |
| 좌표 추정 | Haversine 직선거리 × 1.3 **가정**, 실제 도로거리 아님 |
| 경로 API | 서버가 받은 경로만 인정, 20분 만료·사용자/좌표 바인딩 |

주소는 사용자가 직접 입력하고 검색 후보를 선택합니다. 현재 위치/GPS를 몰래 수집하지 않습니다. 키가 없으면 주소/거리 수동 입력이 유지됩니다. 주소·경로 전송은 별도 동의를 받습니다.

- 카카오 주소 공식 문서: https://developers.kakao.com/docs/latest/ko/local/dev-guide#address-coord
- 카카오 자동차 길찾기: https://developers.kakaomobility.com/docs/navi-api/directions/
- API 주소: `https://dapi.kakao.com/v2/local/search/address.json`, `https://apis-navi.kakaomobility.com/v1/directions`
- 반환 경로는 승용차 기준이므로 화물차 높이·중량 제한/통행료를 확정하지 않습니다.

견적 기록에는 입력 조건, 계산 결과/단가 버전/시각/거리 출처가 저장되며 생성 사용자만 조회합니다. 업체에 견적을 보내거나 배차·예약·결제하지 않습니다. 철거·설치·보험·도서/도선·주차·대기 비용은 별도입니다.

## 5. 설정과 제한

`.env.example`의 새 항목을 사용합니다. 키는 서버/컨테이너의 비밀설정에만 보관하고 `VITE_` 접두사나 클라이언트 번들에 넣지 않습니다. NAS Compose에는 명시적 전달 항목을 추가했습니다. 기본값은 모두 false/빈 문자열입니다.

| 기능 | 필요한 서버 설정 |
|---|---|
| 조달 조회 | `PROCUREMENT_ENABLED=true`, `DATA_GO_KR_SERVICE_KEY` + 이용승인 |
| 참고사진 | 위 설정 + `PROCUREMENT_IMAGE_RIGHTS_CONFIRMED=true` (이용조건 확인 후) |
| AI | `AI_ENABLED=true`, `AI_DATA_APPROVED=true`, `OPENAI_API_KEY`, 실제 지원 확인한 `AI_MODEL` |
| 주소 검색 | `LOCATION_ENABLED=true`, `KAKAO_REST_API_KEY` |
| 도로 경로 | `ROUTE_ENABLED=true`, `KAKAO_MOBILITY_REST_API_KEY` |
| 사용자 단가표 | `SHIPPING_RATE_CARD_JSON` (`server/shipping.mjs` 스키마 참조) |

상태의 '설정됨'은 자격값 존재 표시이며 실제 API 성공 보장이 아닙니다. 테스트용 fake 키/응답은 테스트 파일에서만 사용합니다. 실제 API 키·기관 승인 미확보 상태에서는 live 호출·사진 권리·업체단가를 검증하지 못했습니다. 운영 전에 소량 합성 사진과 공개 모델명으로 공급자별 smoke test를 수행하세요. AI는 시간당30회 등록보조 요청, 기본 일20회 모델 호출 한도를 두며 공급자 예산 한도도 별도 설정해야 합니다.

## 6. 저장·배포

SQLite `user_version=2`의 추가 테이블만 만듭니다. 기존 물품·자산·사용자·첨부는 삭제/초기화하지 않습니다. 업그레이드 전 앱을 중지하여 DB+uploads 일관된 백업을 만들고 별도 경로 복원을 확인한 뒤 진행하세요. v2에 기록한 데이터를 과거 버전 코드로 덮어쓰지 않습니다. 롤백은 원본 보존 상태에서 별도 복원경로로 진행합니다.

기존 HTTPS 출처·Secure 쿠키·NAS 호스트 포트·네트워크 서브넷을 보존합니다. 이번 변경은 NAS 운영 데이터를 읽거나 서비스를 재배포하지 않았습니다. 자세한 실제 환경 마무리는 [CODEX_V04_DEPLOY.md](CODEX_V04_DEPLOY.md)를 따릅니다.
