## UI 증거와 제외
새 화면의 URL·제목(쓸모잇다), 의미있는 heading, 버튼동작, 금액변경, 근거 접힘,
Vite 오류 오버레이 없음, JS pageerror 없음, 390px 가로넘침 없음 확인.
초기 미로그인 /api/auth/me의401은 정상적인 세션검사이며 그 한 경로만 예상 콘솔응답으로 구분한다.
그 밖의 console error/warn은 새 시나리오에서0건이었다.

`TRANSPORT_CAPTURE_DIR`를 지정해 테스트를 실행하면 실제 합성데이터 운송 화면 PNG가
지정한 테스트 증거 폴더에 생성된다. 원본 스크린샷과 테스트 보고는 CI 증거로 제공하고
스크린샷·폰트파일을 실행 소스에 복제하지 않는다. 캡처의 최종 육안 대조는 Codex 인계에 포함한다.

카카오 우편번호 SDK의 embed 결과는 테스트 대역으로 검증했다. 실제 공식 위젯의 운영 HTTPS
로드·CSP·주소선택, 실제 키를 이용한 카카오/모델 응답, 실제 포장 치수/운송업체 견적은
최종 배포 환경에서 별도로 검증해야 한다. 사용자 환경에 키가 없으면 기능을 허위 활성화하지 않는다.
